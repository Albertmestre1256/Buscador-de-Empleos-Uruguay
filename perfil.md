# Perfil de búsqueda laboral

Este es un ejemplo editable para una persona que busca trabajo como analista de
datos comerciales. No describe automáticamente a quien usa el repositorio.
Reemplazá las secciones con información verdadera antes de usar las recomendaciones.

## Puestos y áreas de interés
- Objetivo principal: analista de datos comerciales junior.
- También me interesan: reporting comercial, inteligencia de negocios (BI),
  análisis de ventas y apoyo al análisis estadístico en organismos públicos.

## Restricciones y requisitos

evidencia de formación o experiencia; no asumir que 'por completar' es un mérito.
